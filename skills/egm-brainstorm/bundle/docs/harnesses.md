# Other harnesses and direct fallback

Read runtime.md. Antigravity/Gemini CLI/Cursor/Copilot can discover ordinary skill files only where their installed version supports the relevant directory. Discovery does not establish invocation, fresh isolation, nested delegation, permissions, artifact persistence, interactive approval or runtime verification.

Before review inspect actual subagent documentation. If it provides fresh contexts, use a general reviewer with canonical persona/rubric and explicit read allowlist; if nesting is absent, the parent dispatches directly. Stop with not_run when no verified fresh dispatch exists. These adapters do not install plugins or invent harness APIs. Ordinary design drafting/drift analysis can operate without Goldfish; independent design-review claims require real fresh execution evidence.
